# Guessing game 
 
You are guessing a number of the chamber that is randomized by the computer and  you may use the color hints and hint button to help you get the number and gain coins

## How to play
 
1. you start with a number you want to try guessing and check if your number is right or not
2. you may keep trying until you get the right number 

## What I added
 
- I've added warm or cold hints by adjusting the colors of the screen when you get closer or further from the secret number
- I've added difficulty levels now at the top of the game you may choose easy medium or hard games that gives you number ranges from 1-10, 1-100, 1-1000
- I've added the best score/ record for the game now if you keep playing for a while you can see your best record which is the least time used to guess the secret number
- I've added a hint button to show a hint of if the number is even or odd at the bottom of the game to help
- I've added a theme to the game now instead of guessing numbers and being boring now we are opening chambers to earn coins which make the game better by changing the text
- I've changed the symbols next to the text guessing game at the top and the symbol when you get the right answer
